# Tecmi Park - Sistema de Estacionamiento

Sistema de control de estacionamiento desarrollado en Python como parte de la práctica de Laboratorio del Ciclo de Vida del Software.

## Módulos Implementados
- **Módulo 1:** Registro de ingreso de vehículos (Placa, Tipo, Timestamp de entrada).
- **Módulo 2:** Cálculo dinámico de tarifa por hora redondeada y cobro.
- **Módulo 3:** Monitoreo de disponibilidad de plazas en tiempo real (Capacidad máx: 20).

## Trazabilidad con Jira (Proyecto `TP`)
- **TP-3:** Análisis y especificación de requerimientos de software.
- **TP-5 / TP-9:** Lógica de cotización, tarifas por tipo de vehículo y generación de cobro.
- **TP-6:** Definición y resolución de la problemática operativa del estacionamiento.
